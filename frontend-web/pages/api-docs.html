API Reference

Base URL: http://localhost:5000/api

Authentication

POST /auth/register
POST /auth/login
GET  /auth/profile   (Bearer token)
PUT  /auth/profile   (Bearer token)

Reviews

POST   /reviews/analyze   (Bearer token)
GET    /reviews          (Bearer token)
GET    /reviews/stats    (Bearer token)
GET    /reviews/:id      (Bearer token)
DELETE /reviews/:id      (Bearer token)

Example: Analyze Code

POST /reviews/analyze
Authorization: Bearer <token>
Content-Type: application/json

{
  "prDiff": "diff --git a/file.js ...",
  "prTitle": "Add feature",
  "prNumber": 42
}
